# Quy trình chạy thử CN10 Enterprise

## Nguyên tắc

- Chốt theo ngày, không chốt theo tháng.
- File upload không đi thẳng vào kết quả, mà đi qua lớp Raw Data.
- Engine sinh kết quả, task lỗi, tiền chưa xác định và case master.

## Quy trình

1. Tạo phiên ngày.
2. Upload file.
3. Preview dữ liệu.
4. Import raw.
5. Chạy engine.
6. Xử lý lỗi.
7. Đủ điều kiện hạch toán.
8. Chốt ngày.
